# Changelog

## 1.1.0 — 2026-09-12

- Added a formal project card and nearest-neighbour novelty map.
- Added modified Hartung–Knapp, equal-system, trimmed-mean, sample-size-weighted,
  sign-test, prediction-interval, and leave-one-system-out summaries.
- Added raw-design diagnostics and full PV/BRR sensitivity to minimum within-
  stratum treatment-arm sizes of 2, 5, and 10.
- Corrected the reported first-action specification from a student-level sum to
  the student's mean across applicable LDW items.
- Added four appendix table families, two appendix figure families, and stronger
  release assertions.

## 1.0.0 — 2026-09-12

- Pinned and verified the first audited PISA 2025 PUF release used by the project.
- Reconstructed three mirrored LDW order pairs and a strict within-school sample.
- Implemented system-specific weighted fixed-effect estimation with ten plausible
  values and 80 BRR-Fay replicates.
- Added fixed- and random-effects cross-system synthesis.
- Added balance, comparative-advantage, process, learner-heterogeneity, and
  adaptive-science analyses.
- Released six table families, four figure families, system estimates, unit
  tests, 27 result assertions, and a SHA-256 package manifest.
- Documented source provenance, identification limits, variable definitions, and
  deviations from the feasibility blueprint.
